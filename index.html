📊 구글 스프레드시트 실시간 자동 연동 (무료 웹앱) 미설정

구글 시트의 [확장 프로그램 ➔ Apps Script]에서 웹앱으로 배포한 URL을 아래에 입력해두시면, 직원이 엑셀 파일을 분석할 때마다 구글 시트에 [날짜, 시간, 파일명, 실인원, 연인원, 오류수]가 1초 만에 실시간 행으로 자동 누적 기록됩니다! (비용 0원, 서버 불필요)

📌 구글 시트 1분 연동 가이드:
  1. 구글 드라이브에서 새 구글 스프레드시트를 만듭니다.
  2. 상단 메뉴에서 [확장 프로그램] ➔ [Apps Script]를 클릭합니다.
  3. 기존 코드를 지우고 아래 코드 10줄을 복사해서 붙여넣고 저장(Ctrl+S)합니다:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["기록일시", "파일명", "시트수", "실인원(명)", "연인원(건)", "단체수(건)", "적발오류수(건)"]);
  }
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([data.timestamp, data.fileName, data.sheetCount, data.actualUsers, data.totalAccum, data.groupCount, data.issuesCount]);
  return ContentService.createTextOutput(JSON.stringify({result: "success"})).setMimeType(ContentService.MimeType.JSON);
}
  1. 우측 상단 [배포] ➔ [새 배포] 클릭 ➔ 유형: 웹 앱 선택
  2. 액세스 권한: 모든 사용자(Anyone)로 설정 후 [배포] 클릭 ➔ 나온 웹 앱 URL 복사 후 위 입력창에 붙여넣기 끝!
